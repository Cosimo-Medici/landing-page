Accessibility

Website Accessibility

We want everyone to be able to learn about Cosimo, explore the examples, and contact our team. We use the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA to guide improvements to this website.

Using the website

  • Use Tab and Shift+Tab to move between links and controls. The first link lets you skip the navigation and reach the page content.
  • Use Enter or Space to activate buttons and expand FAQ answers. Press Escape to close a document dialog or the mobile menu.
  • Use the “Pause animations” control to stop decorative motion and automatic walkthroughs. The site also respects your device’s reduced-motion setting.
  • You can zoom with your browser and switch between light and dark themes. Wide example tables can be scrolled horizontally with the arrow keys when focused.

Get help or report a problem

Email info@medici.ai if a page or control prevents you from accessing information. Include the page address, what you were trying to do, and the format or assistance that would help. Browser or assistive-technology details are useful if you wish to share them; you do not need to disclose a disability or medical information.

You can also use that address to request the information in a different format or arrange a walkthrough with our team.

Ongoing review

We review keyboard access, text contrast, responsive layouts, and animation controls as the site changes. The interactive product examples include detailed tables and document viewers; if any part is difficult to use with your setup, please let us know so we can address it.
